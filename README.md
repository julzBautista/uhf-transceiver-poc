# UHF Transceiver Proof of Concept

Custom **436 MHz UHF transceiver PCB** developed for a CubeSat communications system as part of **CalgaryToSpace**. The project focuses on RF circuit design, controlled-impedance PCB layout, power amplification, filtering, and hardware testability.

The board is built around the **Silicon Labs SI4463** transceiver and is designed to target approximately **30 dBm (1 W) RF output power** in the amateur UHF band.

## System Overview

**Transmit Path**

`SI4463 → Power Amplifier → 5th-Order Chebyshev LPF → RF Switch → Antenna`

**Receive Path**

`Antenna → RF Switch → LNA / Filtering → SI4463`

The board also integrates an **STM32F401** microcontroller for transceiver control and system interfacing.

## Design Highlights

* **4-layer RF PCB** designed in Altium Designer
* Operation around **436 MHz**
* Target transmit output power of **30 dBm**
* **SI4463** UHF transceiver
* External RF **power amplifier**
* Custom **5th-order Chebyshev low-pass filter** for PA harmonic suppression
* **50 Ω controlled-impedance coplanar waveguide (CPWG)** RF routing
* Ground stitching and via fencing around sensitive RF paths
* RF and digital sections arranged to reduce coupling and interference
* Integrated RF switching between transmit and receive paths
* Dedicated RF test points for subsystem-level characterization
* On-board power regulation for the required system rails

## PCB

The RF layout was designed with particular attention to:

* Maintaining continuous RF return paths
* Minimizing high-frequency interconnect lengths
* Controlled 50 Ω transmission lines
* Via fencing and ground stitching
* Isolation between RF, digital, and power circuitry
* Placement of matching and filtering components close to their associated RF devices

## RF Output Filtering

A custom **5th-order Chebyshev low-pass filter** was designed for the transmitter output to attenuate harmonics generated by the power amplifier while maintaining low insertion loss across the intended UHF operating band.

`PA → Chebyshev LPF → RF Switch → Antenna`

## Hardware Validation

The PCB includes accessible RF interfaces and test points to support characterization during board bring-up, including measurements of:

* Transmit output power
* Harmonic content
* Filter response
* RF signal integrity
* Power rails
* Transceiver communication and control

Testing is intended to use equipment including a **VNA, spectrum analyzer, oscilloscope, signal generator, and digital multimeter**.
